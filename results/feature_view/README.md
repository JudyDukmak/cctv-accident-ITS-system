# Feature view: saved type-probe features (fold model 1, t_hat window)

`pca_map_type.png` shows the 2,211 synthetic clips' Classifier features (C_cctv seed 0, fold model 1, t_hat window, mean of original and flipped frames, standardised) projected on the first two principal components, which hold 16.2% and 7.3% of the variance; the first 10 components hold 46.2% (`pca_variance.csv`). On the left the points are coloured by map and on the right by collision type, and each label marks a group's centroid. The silhouette scores on the full 768 standardised numbers are close to zero for every grouping (all clips: map 0.0279, scenario 0.0282, type 0.0034; shuffled labels -0.0065 to -0.0267), and on the 755 fold-1 clips the encoder never trained on they are higher for map (0.0889) than for type (0.0756, equal to scenario because each fold-1 type is one scenario) (`silhouette.csv`). *Interpretation:* no grouping forms tight clusters, but the points group by map more than by collision type over all clips, and in the figure Town07, Town06 and Town04 sit in visibly different regions while the type centroids sit close together near the middle. This fits the two failed probe attempts; it is a description of one fold model and one window, not a test.
