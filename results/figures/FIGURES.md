# Report figures

Synthetic 3-fold cross-validation only (no real data). PNG at 300 dpi. Colours: C_v2 orange, C_cctv blue (seeds 0 / 1 / 2 = dark / mid / light blue), C_cos3 green. "Frozen" post-processing = smoothing 3 + parabolic peak interpolation + flip TTA (RUNS.md "Post-processing"); "default" = smoothing 3, no interpolation, no TTA. Commands run from `cctv-accident-ITS-system\` in the training environment (CPU; no figure needs the GPU). Logs: `overfit_vs_lr_report_figures.log`, `report_figures.log`.
